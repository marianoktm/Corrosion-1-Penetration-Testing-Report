# Corrosion: 1 — Penetration Testing Project

Penetration testing assessment of the **Corrosion: 1** vulnerable virtual machine from [VulnHub](https://www.vulnhub.com/), conducted as part of the **Penetration Testing and Ethical Hacking** examination project.

The objective of the project was to perform a complete penetration test against the target machine, identify and exploit security vulnerabilities, obtain unauthorized access within the defined lab environment, and document the methodology, findings, exploitation process, and results.

### `latex_report/`

Contains the **LaTeX source code** used to generate the penetration testing report.

The source files allow the report to be inspected, modified, and reproduced from its original source.

### `latex_reproduction/`

Contains the **LaTeX source code** used to generate the reproduction guide.

The reproduction guide provides the technical steps required to reproduce the relevant phases of the assessment in the intended laboratory environment.

### `attachments/`

Contains supporting material produced or used during the assessment, including:

* Tool output and reports
* Exploit source code
* Other technical artifacts relevant to the penetration test

These files provide additional technical evidence supporting the findings documented in the main report.

### `PENTEST REPORT - CORROSION 1.pdf`

The final penetration testing report.

It documents the assessment methodology, reconnaissance and enumeration activities, identified vulnerabilities, exploitation procedures, post-exploitation activities, evidence, and conclusions.

### `REPRODUCTION GUIDE - CORROSION 1.pdf`

The final reproduction guide.

It documents the procedures necessary to reproduce the penetration testing activity and validate the documented findings in the laboratory environment.

### `PRESENTATION - CORROSION 1.pdf`

The presentation of the penetration testing activity.

It highlights the key steps that were followed to execute the penetration testing assessment.

## Assessment Target

## Scope and Disclaimer

This project was conducted exclusively against the intentionally vulnerable **Corrosion: 1** virtual machine within an authorized laboratory environment.

The techniques, exploit code, commands, and procedures contained in this repository are provided for **educational and authorized security-testing purposes**. They should not be used against systems, networks, applications, or devices without explicit authorization from the respective owner.

## Academic Context

This repository was developed as part of an examination project for the **Penetration Testing and Ethical Hacking** course.

The project demonstrates the practical application of penetration testing concepts including reconnaissance, enumeration, vulnerability identification, exploitation, post-exploitation, evidence collection, and technical reporting.
